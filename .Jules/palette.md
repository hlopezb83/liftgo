# Palette's Journal

## 2026-11-06 - Escape key pattern for search inputs

**Learning:** In desktop and keyboard navigation workflows, users expect `Escape` on search inputs to act as a two-stage dismiss: the first press clears active search text without leaving the field, and a second press (or pressing when empty) unfocuses/blurs the field to return keyboard focus back to the page context.
**Action:** Always provide `Escape` key handling on search inputs to mirror standard desktop UX and avoid forcing keyboard-first users to reach for the mouse or backspace repeatedly.
