## 5. REP drain: observable completion, not a guessed delay

The old handler can await PAC and later write `error` (`4de7d314…/handler.ts:250–259,535–556`), or perform downloads/uploads and later writes (`:585–667`). A 30-second sleep, 504 response, empty `pg_stat_activity`, or deploying the new function does not prove old requests are finished.

Require a named operator to establish this evidence in order:

1. **Fence admissions:** block every path that can start the affected old writers, including direct API calls, UI clients, retries, scheduled work and already queued dispatches. Identify what existing platform control provides this. No verified maintenance switch exists in the inspected REP entry/handler. A human request not to click is insufficient unless the complete caller set and queued work are actually controlled.
2. **Set the last-admission boundary:** record a server-time boundary only after admission/dispatch queues are closed. Identify the old deployed revision(s), region coverage and outstanding executions.
3. **Prove worker retirement:** use authoritative completion/termination records for all old executions, or a provider-verified hard upper bound on worker lifetime plus assurance that no old invocation can start after the boundary. Account for queued dispatch and clock/observation uncertainty. Do not assume a platform-wide number applies to this target.
4. **Prove no late database work:** after retirement, confirm previously sent write requests/transactions and other queued writers are no longer capable of committing. Database activity is supporting evidence here, not a substitute for worker retirement.
5. **Preserve PAC uncertainty:** worker termination does not prove PAC never issued a REP. Keep unresolved claims protected for the existing authorized reconciliation process. Do not mark them `error`, clear claims, or retry issuance merely because time elapsed.
6. Keep the fence until corrected REP code identity, 0105, the remaining stages and coordinated verification are established. Any renewed old execution resets the drain proof.
